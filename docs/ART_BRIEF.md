# Dog Art Brief - generating the pet in the Gemini app

The dog art is generated by hand in the **free Gemini app** (gemini.google.com or
Google AI Studio). The running name here is **Biscuit** - rename freely.

**v1 = one dog.** Generate this single dog in all the poses below. Breed/colour
options come later - don't generate variants yet.

---

## Workflow

1. **Reference first.** Paste the *Reference prompt* into the Gemini app, generate
   a few, pick the one you love most. That image is now *the* dog. Save it as
   `dog-reference.png` and **send it to me before generating the rest** - we lock
   the look first.
2. **Each pose.** Start a new prompt, **attach `dog-reference.png`**, and paste
   the pose prompt. Attaching the reference every time is what keeps it the same
   dog.
3. Save each result with the filename given below, into `src/assets/pet/` in the
   repo.
4. I then handle background removal, layer-slicing, rigging and animation.

## Specs - apply to every image

- **Square** (1:1).
- **Plain flat solid background** - one pale colour, no scene. If the app offers
  a transparent / PNG-with-alpha option, use it. (We cut the dog out either way.)
- Just the dog - plus the one named prop where a pose calls for it. **No text, no
  borders, no extra objects.**
- Whole dog visible, centred, a little margin around it.

## Style line - keep this identical in every prompt

> soft rounded cartoon storybook illustration, clean bold outlines, smooth flat
> cel-shading, gentle and friendly

---

## Reference prompt

> A cute cartoon illustration of a friendly puppy - a cream-and-tan dog with soft
> floppy ears, a rounded head, big warm dark eyes, a small black nose and a
> little tail. Soft rounded cartoon storybook illustration, clean bold outlines,
> smooth flat cel-shading, gentle and friendly. The puppy sits upright facing
> forward with a calm, happy expression. Full body, centred, plain flat pale
> background, no text, no props. A mascot character for a cozy, minimalist
> wellness app.

## Tips for consistency

- Reuse the **same words** for the dog every time ("cream-and-tan", "soft floppy
  ears", "big warm dark eyes") - drift comes from varied descriptions.
- If a pose comes back off-model, regenerate with the reference re-attached
  rather than tweaking wording.
- Keep the bed prop (`stuffed`, `sleeping`) the same simple round bed each time.
- Do the **reference + one test pose first**, check with me, *then* grind the
  rest - cheaper than redoing all ten.
